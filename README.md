# YAW public privacy-policy site

This repository is ONLY for publicly accessible privacy information. **Do not upload the private YAW application source, keystores, signed/unsigned release bundles, or internal evidence.**

The user-site repository must be named exactly `masterramy.github.io` under `masterramy`, with **Public** visibility. Configure Settings > Pages > Deploy from a branch > `main` > `/(root)` > Save.

The app's existing in-app and intended Google Play privacy URL is:

https://masterramy.github.io/yet-another-widget/privacy/

`yet-another-widget/privacy/index.html` faithfully preserves the Nov 1, 2026 approved policy text as recovered from YAW's private `gh-pages` branch. **Necessary adaptation:** privacy inquiries now link to this public, dedicated repository's issue tracker rather than the YAW source repository, which is now private. Enable Issues in Settings > General > Features. Do not post personal data in public issues.

This repo is intentionally public. It contains only legal disclosure HTML and no Android source.
